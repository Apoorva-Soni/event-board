# Campus Event Board

A simple and responsive Campus Event Board website created using HTML5 and CSS3.

## About the Project

This website helps students view different campus events, check the event schedule, and register for events.

## Features

- Campus event banner
- Event cards with images and descriptions
- Event schedule table
- Event submission form
- Event registration form
- Responsive layout for different screen sizes
- Accessible navigation and form elements
- Styled buttons, links, tables, and forms

## Technologies Used

- HTML5
- CSS3

## Project Files

- `index.html` – Main webpage
- `style.css` – Main styling
- `theme-dark.css` – Theme styling, if used
- `base.css` – Base styling, if used
- `images/` – Project images, if used
